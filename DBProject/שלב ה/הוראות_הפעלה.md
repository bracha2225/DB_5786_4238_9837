# שלב ה' – ממשק גרפי לניהול בסיס הנתונים הרפואי

## 📖 תיאור כללי

בשלב זה פיתחנו ממשק גרפי מלא (Web Application) המחבר בין בסיס הנתונים PostgreSQL שבנינו בשלבים הקודמים לבין משתמש קצה. האפליקציה מאפשרת ביצוע כל פעולות ה-CRUD (יצירה, קריאה, עדכון, מחיקה) על כל הטבלאות, הרצת שאילתות SQL, והפעלת פונקציות ופרוצדורות שנכתבו בשלב ד'.

---

## 🛠️ כלים וטכנולוגיות ששימשו לבניית האפליקציה

### Backend (שרת)
| כלי | גרסה | מטרה |
|-----|-------|-------|
| **Python 3** | 3.8+ | שפת תכנות לשרת |
| **Flask** | 3.x | מסגרת עבודה (Framework) לבניית REST API |
| **psycopg2-binary** | 2.x | ספריית Python לחיבור ל-PostgreSQL |

### Frontend (ממשק)
| כלי | מטרה |
|-----|-------|
| **HTML5** | מבנה הדף |
| **Vanilla CSS3** | עיצוב – כולל Glassmorphism, גראדיאנטים, אנימציות |
| **Vanilla JavaScript (ES5+)** | לוגיקת הצד הלקוח – Fetch API, DOM Manipulation |
| **Font Awesome 6** | אייקונים |
| **Google Fonts – Assistant** | גופן עברי מודרני |

### מסד הנתונים והתשתית
| כלי | מטרה |
|-----|-------|
| **PostgreSQL 17** | מסד הנתונים הרלציוני |
| **Docker + Docker Compose** | הרצה של מסד הנתונים ו-pgAdmin בסביבה מבודדת |
| **pgAdmin 4** | ממשק ניהול גרפי למסד הנתונים (http://localhost:8080) |

### דרך העבודה
האפליקציה בנויה בארכיטקטורת **Client-Server**:
- ה-**Frontend** (HTML/CSS/JS) רץ בדפדפן ושולח בקשות HTTP ל-API
- ה-**Backend** (Flask) מקבל את הבקשות, מבצע שאילתות על PostgreSQL ומחזיר JSON
- כל הלוגיקה בצד השרת – הלקוח רק מציג ומאסף קלט

## 🚀 הוראות הפעלה

### דרישות קדם
1. **Docker Desktop** – מותקן ופעיל
2. **Python 3** (גרסה 3.8+)
3. ספריות Python – Flask ו-psycopg2-binary

### שלב 1: התקנת ספריות Python (פעם אחת בלבד)
```bash
pip3 install flask psycopg2-binary
```

### שלב 2: הפעלת מסד הנתונים
מתיקיית השורש של הפרויקט:
```bash
docker compose up -d
```
> מסד הנתונים יהיה זמין על פורט **5433**.  
> pgAdmin יהיה זמין בכתובת [http://localhost:8080](http://localhost:8080)

### שלב 3: הרצת האפליקציה
```bash
cd "DBProject/שלב ה"
python3 app.py
```

### שלב 4: פתיחת הממשק
פתחו את הדפדפן וגשו לכתובת:

> 🌐 **http://localhost:5001**

> **הערה:** האפליקציה רצה על פורט 5001 (ולא 5000) כדי למנוע התנגשות עם שירות AirPlay של macOS.
